# SB Certificate Generator

SB Vocational Training Centre-এর জন্য সার্টিফিকেট বানানোর ওয়েবসাইট — সেন্টারকে উপহার।

## ব্যবহার

1. GitHub Pages লিংকটি খুলুন (repo-র Settings > Pages থেকে main branch, root দিয়ে চালু করলে পাওয়া যাবে)।
2. ফর্মে লিখুন: শিক্ষার্থীর নাম, লাইসেন্স নম্বর (হাতে টাইপ করা যায়), লেভেল, কোর্সের নাম, শুরু/শেষের তারিখ, মেয়াদ, মোট ঘণ্টা, সেন্টারের নাম।
3. পাশে লাইভ প্রিভিউ দেখুন — ডেমো সার্টিফিকেটের ডিজাইনে, সেন্টারের লোগোসহ।
4. এক ক্লিকে A4 ল্যান্ডস্কেপ PDF ডাউনলোড করুন।

## গোপনীয়তা

সবকিছু ব্রাউজারেই হয়, কোনো ফাইল সার্ভারে যায় না।

## ফাইল

- `index.html` — সম্পূর্ণ ওয়েবসাইটটি (একটি ফাইলেই চলে)
